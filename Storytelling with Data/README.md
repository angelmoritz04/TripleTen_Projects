# Storytelling with Data

## Overview
<p>This analysis was made to more thoroughly determine what is causing returns at Superstore, and how to eliminate or improve items that have a high rate of return. This was then presented within a Tableau story, so the issue could be fully understood and analyzed by me, the analyst.</p>

## Features and Functionality
- Multiple charts showing the returns by category, subcategory, customer, and geographical location.
- Composite charts with a mix of factors contributing to returns <i>(region/month, state/category)</i>
- An examination into parameters, changing visuals to show percentages, sums, or averages depending on what's chosen.
- Filters applied to each chart to erase users or orders that are not relevant to the data we're examining (e.g. users who have only purchased one item).

## Findings of the Analysis
- Utah has a 57% return rate, which may mean deliveries there are getting broken or are just not of the quality expected
- Machines have a 35% return rate overall. Machines should be updated or, if they are breaking on the way to their destinations, packaging should be changed to keep these items safe.
- August has the highest return rate of any month at 39%. This could be due to the start of the school year, or other factors.
