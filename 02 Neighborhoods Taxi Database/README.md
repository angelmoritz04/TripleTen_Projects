# Neighborhoods Taxi Database

## Overview

<p> Used MySQL to search through a ridesharing app's database, and draw insights on passenger preference and the impact of external factors on rides. </p>

## Features and Functionality
- I studied the use of different SQL functions with this project, including unique JOIN styles, DATE_TRUNC, WHERE, ORDER BY, etc.
- A feature of this project was the complex "WHERE" functions, built on several identifiers to extract specific data on date/time, weather, and drop-off location 
- This project was built using a database built (or at least maintained) by my study program.

## Findings of the Analysis
- Discovered that taxi services with the word "Yellow" in their title received close to 2x as many users as those with the word "Blue"
- Found the nubmer of users for each taxi company, and listed them in descending order
- Determined the start time, duration, and weather conditions of every taxi ride in the database by joining three seperate tables together.
